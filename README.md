# GEA1000 Project Part B: Python analysis

Python analysis for Part B, Questions 1 to 5, of the GEA1000 group project on the video games dataset (1,754 games, where a game is a title on one console).

## Files
- `Python Analysis/GEA1000_PartB_Analysis.ipynb`: the Jupyter notebook with all the code, outputs and short notes for each question.
- `Video_games_dataset.csv`: the dataset used by the notebook.

## How to run it
1. Install Python 3, then the libraries: `pip install pandas numpy scipy matplotlib jupyter`.
2. Keep the folder layout as it is, so the notebook finds the data at `../Video_games_dataset.csv`.
3. From the `Python Analysis` folder, run `jupyter notebook GEA1000_PartB_Analysis.ipynb`, then choose Kernel > Restart & Run All.

Libraries: `pandas` (tables), `numpy` (calculations), `scipy` (statistics) and `matplotlib` (charts).
